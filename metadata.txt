description=A professional, ArcGIS Pro style workspace for QGIS: a categorized ribbon with contextual layer tabs, a print-layout gallery for map making, a collapsible ribbon and Maximize Map, and tabs for Parcel Fabric, NENA Addressing and RCL Tools, Align Edge and COGO Workbench.
about=Workspace Ribbon replaces QGIS's menu bar and toolbars with a ribbon organized the way ArcGIS Pro users expect: Map, Insert, Layout, Analysis, View, Edit, Imagery, Share and Help, plus Parcels and Addressing tabs for the Parcel Fabric and NENA Addressing and RCL Tools plugins, Align Edge and COGO Workbench on the Edit tab, and an Add-ins tab only for plugins it doesn't know. Selecting a layer in Contents adds Pro's contextual tabs (Feature Layer: Appearance, Labeling, Data; Raster Layer; Standalone Table). For map creation, New Layout opens a gallery of ANSI and ISO page sizes that builds a finished map sheet (map, title, legend, north arrow, scale bar, footer) or a blank page, lists your own .qpt templates, and Export Layout writes one or all layouts to PDF. For room to work, double-click a tab or press Ctrl+F1 to collapse the ribbon, and use View > Maximize Map to hide all panes. Switching it off restores QGIS exactly as it was. Built on ArcSkin by EnviroSolutions (GPL-2.0-or-later): its light theme, Pro-style icons, panes, map status bar, basemaps and symbology. Replaces ArcSkin; switch one of them on at a time. Not affiliated with or endorsed by Esri; ArcGIS and ArcGIS Pro are trademarks of Esri.

changelog=
    0.2.1 - Save All button (Ctrl+Alt+S) next to Save on the Quick Access row, on Edit > Manage Edits and in the Project menu: saves the edits of every layer being edited (they stay in edit mode), then the project.
    0.2.0 - Attributes pane (as in Pro): selecting features with a Select tool or Select By Attributes opens a pane listing the selected features by layer, with the picked feature's fields stacked vertically in the layer's own form; click a layer to edit all its selected features at once. Auto Apply writes changes as you type and a click in the fields starts editing. Attributes buttons on Map > Selection and Edit > Features. Docking: right-click a pane's title for Dock Left, Dock Right, Float, Dock All Floating Panes; View > Docking group; Reset Panes re-docks floating panes; nested and tabbed docking switched on.
    0.1.0 - First version: categorized ribbon with Parcels and Addressing tabs, Align Edge and COGO on the Edit tab, contextual layer tabs, Layout tab with a New Layout gallery and PDF export, collapsible ribbon (Ctrl+F1), Maximize Map, editing tools on the Quick Access Toolbar. Based on ArcSkin 0.6.1.
