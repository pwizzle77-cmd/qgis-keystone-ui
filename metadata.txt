about=Keystone is a standalone skin and ribbon workspace for QGIS. Native tools are organized into Map, Insert, Layout, Analysis, View, Edit, Imagery, Share and Help tabs, with contextual layer tabs, layout galleries, Locate, Attributes, Create and Modify panes. Customize Ribbon creates your own named tabs from installed plugin or QGIS toolbars; unassigned plugin tools stay on Add-ins. No parcel or addressing plugin is required or configured by Keystone. Collapse the ribbon with Ctrl+F1 or use Maximize Map for more room. Switching it off restores the previous QGIS interface. Based on ArcSkin by EnviroSolutions (GPL-2.0-or-later); use only one skin at a time. Independent of Esri.

changelog=
    0.7.0 - Generic optional tool placement: plugins declare existing actions for built-in ribbon groups and Modify Features; entries update automatically on registration/unload without restarting the skin or importing other plugins
    0.6.0 - Customize Ribbon: create, rename and reorder profile-local tabs, assign named toolbars without plugin-specific imports, remember missing plugins, and refresh custom/Add-ins pages without restarting the skin
    0.5.0 - Standalone QGIS skin: generic Add-ins and layer search without plugin-specific imports or tabs; retain failed attribute edits with explicit discard; unique batch PDF filenames and overwrite confirmation; preserve basemaps when replacement fails
    0.4.1 - Layer names are readable when Windows is in dark mode. The light skin now also gives QGIS a light colour palette (QGIS colours layer names from the palette, which dark mode made white on the skin's white panels); switching the skin off gives the old palette back.
    0.4.0 - Renamed from Workspace Ribbon to Keystone (plugin folder keystone). Settings, the window layout to restore, basemaps and feature-template presets carry over; remove the old workspace_ribbon plugin.
    0.3.3 - Locate: Search in All layers (now also every other layer, in all its fields) or one layer, and in one field or all of its fields.
    0.3.2 - Edit tab has a Selection group (Select and Clear), as in Pro, so you can pick or clear features, or leave Align Edge, without going back to the Map tab.
    0.3.1 - The floating sketch toolbar now shows at the bottom of the map with QGIS's own digitizing tools (it never appeared: QGIS's C++ capture tools weren't recognised), and in a vertex version while the Vertex tool is active (Snapping, Advanced Digitizing, Vertex Editor, Delete vertex, Undo, Finish F2, Cancel). Selection chip, as in Pro: a click with the Select tool picks the top-most feature on any selectable layer, and where several features overlap a small chip next to the cursor lists them by layer (hover to highlight, click to select that one).
    0.3.0 - More of ArcGIS Pro: Create Features pane (feature templates per layer and category, construction tools, template attribute defaults) with a floating sketch toolbar (Finish F2); Modify Features pane (all editing tools, searchable, with help); Explore tool with feature pop-ups; Locate pane (coordinates, addresses, streets, parcels, OpenStreetMap); attribute tables docked below the map as tabs; Transparency, Visibility Range, Swipe and label Field/Font/Size/Colour/Placement controls on the contextual tabs; a Pro-style ribbon in the layout designer (Layout, Insert, Arrange, Map Series, Share).
    0.2.3 - Esri-style edit sketch: the digitizing rubber band is a solid green 2 px line with a light green fill, circle vertex markers. Only settings still at QGIS's default change; restored when the workspace is switched off.
    0.2.2 - Save All is disabled until there is something to save (unsaved layer edits or project changes), as in Pro.
    0.2.1 - Save All button (Ctrl+Alt+S) next to Save on the Quick Access row, on Edit > Manage Edits and in the Project menu: saves the edits of every layer being edited (they stay in edit mode), then the project.
    0.2.0 - Attributes pane (as in Pro): selecting features with a Select tool or Select By Attributes opens a pane listing the selected features by layer, with the picked feature's fields stacked vertically in the layer's own form; click a layer to edit all its selected features at once. Auto Apply writes changes as you type and a click in the fields starts editing. Attributes buttons on Map > Selection and Edit > Features. Docking: right-click a pane's title for Dock Left, Dock Right, Float, Dock All Floating Panes; View > Docking group; Reset Panes re-docks floating panes; nested and tabbed docking switched on.
    0.1.0 - First version: categorized ribbon with Parcels and Addressing tabs, Align Edge and COGO on the Edit tab, contextual layer tabs, Layout tab with a New Layout gallery and PDF export, collapsible ribbon (Ctrl+F1), Maximize Map, editing tools on the Quick Access Toolbar. Based on ArcSkin 0.6.1.
